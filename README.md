# Dhiraj Joshi Portfolio

This is a self-contained, responsive portfolio for Dhiraj Bahadur Joshi. It uses only HTML, CSS, and a small JavaScript enhancement, so it can be hosted by any static hosting provider.

## Preview locally

From the repository root, serve the folder with any static file server. For example, with Node.js:

```powershell
npx serve .
```

## Deploy to Cloudflare Pages

1. Create a Pages project connected to this GitHub repository.
2. Set the root directory to the repository root.
3. Leave the build command empty and set the output directory to `.`.
4. Deploy.

## Deploy to Vercel

Import the repository into Vercel, leave the framework preset as `Other`, and deploy with no build command. To use a custom domain, add a domain you own in the hosting provider and update its DNS records as instructed.

The contact links use the email address, phone number, LinkedIn profile, and GitHub profile supplied in the CV. No credentials or private data are required by this site.
